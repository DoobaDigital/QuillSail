Formatting help

You can write three ways. Visual looks like the finished piece. Markdown and HTML let you type the formatting yourself. Whichever you choose, your piece is checked before it's shown, so scripts, styles and forms are removed.

Markdown

Type thisTo get
## HeadingA section heading
**bold**, _italic_ and ~~struck~~bold, italic and struck
[link text](https://example.com)A link
- item or 1. itemA bulleted or numbered list
- [ ] item and - [x] itemA task list
> quoteA quotation
`code`Inline code
```python … ```A code block with syntax highlighting
![description](image-url)An image (or use the image button)
| A | B |, then | --- | --- |A table
::: tip … :::A highlighted box (also note and warning)
Text[^1] and [^1]: NoteA footnote

HTML

Use ordinary tags for text, lists, tables, images and links. <details>, <video> and <audio> work too, and <iframe> works for YouTube and Vimeo. In newsletters, video, audio and collapsed sections become links or open text.

Keyboard shortcuts

Ctrl is Command on a Mac. In the visual editor: Ctrl+B bold, Ctrl+I italic, Ctrl+Shift+X strikethrough, Ctrl+E code, Ctrl+K link, Ctrl+Alt+1 to 6 headings, Ctrl+Alt+0 paragraph, Ctrl+Shift+7 numbered list, Ctrl+Shift+8 bulleted list, Ctrl+Shift+9 task list, Ctrl+Shift+B quote, Ctrl+Alt+C code block, Ctrl+Z undo, Ctrl+Y redo. Shift+Enter starts a new line in the same paragraph. Tab moves between table cells and indents lists. Press Escape or Alt+F10 to move from your text to the toolbar.
